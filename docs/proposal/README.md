# Proposal sections, a week at a time

Standing rule 5 in [stage-1/plan.md](../../stage-1/plan.md): each week drafts
its own section while the work is fresh, so the submission tail is a freeze and
a send rather than four days of writing. The assembled artifact is
`submission/proposal.pdf`, 6 to 8 pages, and `scripts/check_submission.py` is
what holds it to that.

| Section | Week | State |
| --- | --- | --- |
| Architecture | 1 | owed |
| Mission and coverage | 2 | owed |
| [Communication architecture](week-3-communication.md) | 3 | drafted |
| Fault recovery and the integrated run | 4 | not yet |

Every number in a section names the run it came off. A figure that cannot cite
a run under `runs/` does not go in.
